  <h1>🎨 Simple Paint App for Android</h1>

  <p>
    A lightweight and intuitive <strong>Paint App</strong> built with Android's <code>Canvas</code> and <code>View</code> components. Users can draw, erase, highlight, and clear the canvas with ease. This app features a minimal UI and a custom drawing view that responds to touch gestures.
  </p>
  
  <h2>✨ Features</h2>
  <ul>
    <li>🖌️ <strong>Pencil Tool</strong> – Draw with a smooth black line.</li>
    <li>✏️ <strong>Highlighter Tool</strong> – Draw translucent yellow highlights.</li>
    <li>🧽 <strong>Eraser Tool</strong> – Erase parts of the drawing.</li>
    <li>🔄 <strong>Clear Canvas</strong> – Start over with one tap.</li>
    <li>👁️ <strong>Toggle Tools Visibility</strong> – Hide or show tools for full-screen drawing.</li>
  </ul>

  <h2>🧱 Built With</h2>
  <ul>
    <li><strong>Kotlin</strong></li>
    <li><strong>Android View System</strong></li>
    <li><code>Paint</code>, <code>Path</code>, <code>Canvas</code>, <code>Bitmap</code></li>
    <li><code>ConstraintLayout</code>, <code>LinearLayout</code>, and custom views</li>
  </ul>

  <h2>🛠️ How It Works</h2>
  <ul>
    <li><code>PaintView</code> is a custom view that captures touch events (<code>MotionEvent</code>) to draw paths.</li>
    <li>Each drawing action is stored in a list to persist on redraws.</li>
    <li>Tools are implemented using <code>ImageButton</code>s with listeners that change the color and stroke size of the paint.</li>
    <li>Clear functionality resets the bitmap and stored paths.</li>
  </ul>

  <h2>🎨 Customize</h2>
  <p>You can easily expand this app with:</p>
  <ul>
    <li>Color picker dialog</li>
    <li>Saving drawings to gallery</li>
    <li>Undo/redo functionality</li>
    <li>Custom brush styles</li>
  </ul>
